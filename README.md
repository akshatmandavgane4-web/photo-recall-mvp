# Photo Recall

A prototype for finding a photo from what you remember about it. Describe the photo in your own words, steer from near-misses, and answer at most three short questions.

Run locally: `pip install -r requirements.txt` then `streamlit run web/app.py`. Needs `GEMINI_API_KEY` or `GROQ_API_KEY`; without one it searches on your exact words.
